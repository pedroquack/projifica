# 📚 Projifica

**Projifica** é uma plataforma web desenvolvida em Laravel, destinada a alunos e professores do IFPR (Instituto Federal do Paraná) que desejam iniciar projetos colaborativos na área de tecnologia e encontrar candidatos com interesse e perfil adequado para contribuir.

## 🚀 Objetivo

Criar um ambiente acessível e colaborativo para facilitar a conexão entre idealizadores de projetos e participantes interessados, promovendo o aprendizado prático, o networking e o desenvolvimento profissional.

---

## 🧩 Funcionalidades Principais

- **Cadastro de Projetos**
  - Definição de vagas disponíveis
  - Prazo de inscrição
  - Conhecimentos requeridos
  - Descrição detalhada e título do projeto

- **Candidatura em Projetos**
  - Usuários podem visualizar e se candidatar aos projetos de interesse

- **Perfil Personalizável**
  - Adição de experiências profissionais e projetos
  - Histórico educacional (faculdade, técnico, cursos, etc.)

- **Portfólio Pessoal**
  - Área dedicada para publicação de projetos desenvolvidos pelo usuário

- **Postagens e Interações**
  - Aba de publicações para compartilhar conteúdos diversos
  - Comentários entre usuários para promover o diálogo e a troca de conhecimento
